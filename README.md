# Portfolio React

A modern React-based portfolio website with improved UI/UX, featuring:

- Responsive design with smooth animations
- Skills section with icons using React Icons
- Interactive Projects showcase
- Contact form

## Getting Started

### Prerequisites

Make sure you have Node.js installed on your system. You can download it from [nodejs.org](https://nodejs.org/).

### Installation

1. Navigate to the project directory:
   ```bash
   cd /Users/chirag/Downloads/my-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

The app will run on [http://localhost:3000](http://localhost:3000).

## Features

- **Home Page**: Hero section, about, skills with icons, projects, contact
- **Responsive Design**: Works on all device sizes
- **Smooth Animations**: Fade-up animations and hover effects

## Technologies Used

- React
- React Router DOM
- React Icons
- CSS3 with custom properties
